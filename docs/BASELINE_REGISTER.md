图覆盖主机命令、串口、行走与升降、共享电机通信、IMU、电池、状态灯、诊断，以及软件停止与物理停止的区别。详细源码位置、公司代码派生参数和图留在本地交付目录；此库不包含公司源码或原始日志。

M0 尚未关闭。关闭条件：现有部署清单中的 firmware build/configuration digest、Jetson commit 和启动覆盖参数与只读审计一致。拿不到这些证据时，后续模型必须明确绑定某个已审计源码版本，并标记部署关联未知。

功能图不是原理图，不证明电源、接线、急停、STO 或制动能力。详细本地审计报告保持为证据来源；本登记只用于研究进度追踪。
